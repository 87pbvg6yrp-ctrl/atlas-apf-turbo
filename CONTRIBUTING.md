# Contributing to ATLAS APF TURBO

ATLAS APF TURBO currently publishes release binaries and public documentation rather than the application source code, so source-code pull requests are not currently the main contribution path.

The most useful contributions are reproducible field reports, bug reports and feature requests.

## Bug reports

Please include:

- ATLAS APF TURBO version.
- Windows version if relevant.
- What you expected to happen.
- What actually happened.
- Exact steps to reproduce the problem.
- Screenshots or error text where useful.

## Incorrect result or classification reports

Please include as much of the following as possible:

- Portal address.
- Galaxy.
- APF version.
- Search scope.
- Relevant filter settings.
- APF result.
- Observed in-game result.
- Screenshots showing the discrepancy.

Do not include account credentials, access tokens, private save data, real names, email addresses or other unnecessary personal information.

## Feature requests

Describe the problem or workflow first, then the proposed feature. Examples include new filters, preset/workflow improvements and UI quality-of-life changes.

A feature request is not a guarantee that the feature will be added.
