# Security Policy

## Supported releases

The newest public release is the supported release line.

## Reporting a security issue

Do not post passwords, access tokens, private account information, personal data or other secrets in a public GitHub issue.

If a report can be described safely without revealing sensitive information, open a normal bug report with only the minimum reproducible details. If disclosure itself would create a security risk, do not publish exploit details publicly.

ATLAS APF TURBO does not require administrator access, a running No Man's Sky process, Python or Visual Studio for normal use of the public Windows build.
